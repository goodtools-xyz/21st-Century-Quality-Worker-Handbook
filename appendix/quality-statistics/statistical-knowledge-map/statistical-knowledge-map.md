# 统计知识地图

## 描述性统计-数量方法

### 位置的度量
- **众数 mode**
  - 定义：出现频率最高的数值
  - 特点：不受极端值影响，适用于分类数据
  - 应用：市场调研、产品偏好分析

- **中位数 median**
  - 定义：将数据从小到大排列后，位于中间位置的数值
  - 计算：
    - 奇数个数据：第(n+1)/2个数值
    - 偶数个数据：第n/2和(n/2+1)个数值的平均值
  - 特点：不受极端值影响，适用于偏态分布

- **分位数**
  - **四分位数**
    - Q1：第25百分位数
    - Q2：中位数（第50百分位数）
    - Q3：第75百分位数
  - **十分位数**：第10、20、…、90百分位数
  - **百分位数**：第p百分位数

### 分布形状的度量
- **偏度 Skewness**
  - 定义：描述数据分布的不对称性
  - 计算：
    - 皮尔逊偏度系数1：(均值-众数)/标准差
    - 皮尔逊偏度系数2：3(均值-中位数)/标准差
  - 解释：
    - 偏度=0：对称分布
    - 偏度>0：右偏（正偏）
    - 偏度<0：左偏（负偏）

- **峰度 Kurtosis**
  - 定义：描述数据分布的陡峭程度
  - 计算：
    - 超额峰度=样本峰度-3
  - 解释：
    - 超额峰度=0：正态分布
    - 超额峰度>0：尖峰分布
    - 超额峰度<0：平峰分布

### 离散程度的度量
- **极差 range**
  - 定义：最大值与最小值之差
  - 计算：R = 最大值 - 最小值
  - 特点：易受极端值影响

- **四分位距 IQR**
  - 定义：上四分位数与下四分位数之差
  - 计算：IQR = Q3 - Q1
  - 特点：不受极端值影响

- **方差 variance**
  - 总体方差：σ² = Σ(X-μ)²/N
  - 样本方差：s² = Σ(X-Ẋ)²/(n-1)
  - 特点：反映数据的离散程度，单位为原数据单位的平方

- **标准差 standard deviation**
  - 总体标准差：σ = √σ²
  - 样本标准差：s = √s²
  - 特点：单位与原数据一致，最常用的离散程度度量

- **变异系数 CV**
  - 计算：CV = (标准差/均值) × 100%
  - 应用：比较不同量纲数据的离散程度

- **平均绝对偏差 MAD**
  - 计算：MAD = Σ|X-Ẋ|/n
  - 特点：不受极端值影响，直观反映数据离散程度

### 变量间的关系
- **相关系数**
  - **皮尔逊相关系数**
    - 计算：r = Σ[(X-Ẋ)(Y-Ẏ)] / √[Σ(X-Ẋ)²Σ(Y-Ẏ)²]
    - 范围：-1 ≤ r ≤ 1
    - 解释：
      - r=1：完全正相关
      - r=-1：完全负相关
      - r=0：无线性相关
  - **斯皮尔曼等级相关系数**
    - 计算：基于变量的秩次
    - 应用：适用于非线性关系或有序分类数据

- **协方差**
  - 计算：Cov(X,Y) = Σ[(X-Ẋ)(Y-Ẏ)]/(n-1)
  - 解释：反映两个变量的线性关系方向和强度

### 探索性数据分析
- **箱线图 Box Plot**
  - 组成：最小值、Q1、中位数、Q3、最大值
  - 应用：识别异常值、比较多组数据分布

- **五数概括**
  - 最小值
  - 第一四分位数(Q1)
  - 中位数(Q2)
  - 第三四分位数(Q3)
  - 最大值

- **异常值检测**
  - 方法：
    - IQR法：小于Q1-1.5×IQR或大于Q3+1.5×IQR的数值
    - Z-score法：|Z| > 3的数值
